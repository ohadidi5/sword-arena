# זירת החרב (Sword Arena) ⚔️

משחק פעולה תלת-ממדי (Three.js) בגוף שלישי שבו אתה לוחם חסר פנים חמוש בחרב קטאנה זוהרת, ונלחם מול גלים של אויבים אדומים ללא נשק.

## 🎮 תכונות המשחק
- **מצלמת גוף שלישי דינמית:** עוקבת ומסתובבת מסביב ללוחם.
- **מנגנון הילוך איטי (Bullet Time):** כל מכת חרב מעבירה את המשחק להילוך איטי דרמטי למשך שנייה אחת!
- **מערכת גלים עולה:** כל גל מוסיף עוד אויבים ומעלה את האתגר.
- **מדדי חיים ונזק מדויקים:**
  - שחקן: 100 חיים, מוריד 10 נזק.
  - אויבים: 30 חיים, מורידים 10 נזק.
- **בקר ג'ויסטיק קומפקטי:**
  - החלקה לכל כיוון: תזוזה ושליטה על זווית המצלמה.
  - לחיצה במרכז (`⚔️`): מכת חרב והילוך איטי.
- **אפקטים וסאונד:** מנוע סאונד מובנה (Web Audio API) ללא צורך בקבצים חיצוניים.
